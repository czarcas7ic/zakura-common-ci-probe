## zakura-keys

### Changed

- The `zcashd-compat` feature now depends on `bip0039` without its default
  `rand` feature, so it no longer pulls in random mnemonic generation or
  `rand` 0.8; legacy seed conversion and the returned mnemonic are unchanged.
  Crates that call `bip0039::Mnemonic::generate` must enable `bip0039/rand`
  themselves
  ([#579](https://github.com/zakura-core/common/pull/579)).
